# React Native Map App with Local Database (Task 2)

Мобильное приложение для управления геолокационными маркерами и привязанными к ним изображениями. Приложение разработано на React Native с использованием Expo, файловой маршрутизации Expo Router, строгой типизации TypeScript и локальной реляционной базы данных SQLite.

## Инструкции по установке

1. Убедитесь, что в системе установлены **Node.js (последняя LTS-версия)** и **Expo CLI**.
2. Склонируйте репозиторий и перейдите в директорию проекта:
   ```bash
   cd map-app
3. Установите все необходимые зависимости. Для гарантии совместимости версий пакетов с текущим SDK Expo используется нативная команда установки:
   npx expo install
4. Запустите сервер разработки с полной очисткой кэша Metro:
   npx expo start -c
5. Отсканируйте появившийся QR-код с помощью мобильного приложения Expo Go (или войдите по адресу) или нажмите a для запуска в эмуляторе Android.

## БД
Хранит основные данные о геолокационных точках.

|Поле|Тип|Ограничения|Описание|
|---|---|---|---|
|`id`|INTEGER|PRIMARY KEY AUTOINCREMENT|Уникальный идентификатор маркера|
|`latitude`|REAL|NOT NULL|Широта местоположения|
|`longitude`|REAL|NOT NULL|Долгота местоположения|
|`created_at`|DATETIME|DEFAULT CURRENT_TIMESTAMP|Временная метка создания записи|

### Таблица `marker_images`
Хранит изображения, привязанные к конкретным маркерам.

|Поле|Тип|Ограничения|Описание|
|---|---|---|---|
|`id`|INTEGER|PRIMARY KEY AUTOINCREMENT|Уникальный идентификатор изображения|
|`marker_id`|INTEGER|NOT NULL, FOREIGN KEY|Ссылка на `id` в таблице `markers`|
|`uri`|TEXT|NOT NULL|Локальный URI-путь к файлу изображения|
|`created_at`|DATETIME|DEFAULT CURRENT_TIMESTAMP|Временная метка добавления изображения|

Реализовано ограничение `FOREIGN KEY (marker_id) REFERENCES markers (id) ON DELETE CASCADE` для автоматического каскадного удаления изображений при удалении родительского маркера.
### Таблица `schema_version`

|Поле|Тип|Ограничения|Описание|
|--- |---|---        |---     |
|`version`|INTEGER|PRIMARY KEY|Текущая версия схемы базы данных|
|`applied_at`|DATETIME|DEFAULT CURRENT_TIMESTAMP|Временная метка применения миграции|
